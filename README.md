# Predictive Modeling

This repository contains machine learning assignments and a mini project covering **regression and classification** using real-world datasets.

## Practice Questions

* Trained a Logistic Regression model on the Titanic dataset
* Created a confusion matrix
* Calculated model accuracy
* Compared Decision Tree and KNN accuracy
* Tuned the `max_depth` parameter of the Decision Tree

## Linear Regression – House Price Prediction

* Loaded and explored the House Prices dataset
* Prepared the data for model training
* Split the data into training and testing sets
* Trained a Linear Regression model
* Predicted house prices
* Evaluated the model using **Mean Squared Error (MSE)** and **R² score**

## Logistic Regression – Titanic Survival Prediction

* Loaded the Titanic dataset
* Handled missing values
* Prepared categorical variables
* Trained a Logistic Regression model
* Predicted passenger survival
* Evaluated the model using **accuracy** and a **confusion matrix**

## Mini Project – House Price Prediction

The mini project focuses on predicting house prices using **Linear Regression**.

### Tasks Completed

* Trained a Linear Regression model
* Generated house price predictions
* Evaluated the model using R² score
* Visualized actual vs. predicted house prices
